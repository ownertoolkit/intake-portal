# Customer Intake Portal

A customizable software template from **[The Owner Toolkit](https://theownertoolkit.co)**.

Next.js 15 + Supabase. Customers visit your URL, fill out the form you designed, and you manage inquiries in a private dashboard.

## For subscribers

Read `START-HERE.md` and follow `INSTALL-WITH-CHATGPT.md`. You do not need to touch code.

## What's inside

- **`portal.config.ts`** — your business name, brand color, welcome message, logo path, and form fields. Regenerated by the Owner Toolkit customizer; edit for small tweaks or re-download to change more.
- **`app/portal/`** — the customer-facing form (also served at `/`).
- **`app/dashboard/`** — the private pipeline (New → Contacted → Quoted → Booked → Won → Lost).
- **`app/login/`** — magic-link sign-in for the portal owner (first person to sign in wins).
- **`app/api/inquiries/`** — server route that validates submissions and inserts them via `service_role`.
- **`supabase/migrations/`** — one SQL file. Paste into Supabase's SQL Editor once, at install time.
- **`lib/`** — Supabase clients, portal config typing, validation helpers.

## Environment variables

Set automatically by the Vercel–Supabase integration:

- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_ANON_KEY`
- `SUPABASE_SERVICE_ROLE_KEY` (server-only — never expose)

## Ownership

You own the code, the database, the storage bucket, and the customer data. Owner Toolkit stores none of it. Canceling your subscription does not stop your portal.
